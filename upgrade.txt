=== 1.4.0 ===
* Performance: O(1) SQL path-based tree indexing implemented in manager::count_category_tree(), eliminating recursive object instantiation.
* Performance: Batched progress writes (PROGRESS_BATCH_SIZE = 3) to reduce job table write contention.
* Performance: Throttled pause checks (PAUSE_CHECK_INTERVAL = 3) to minimize repetitive DB reads.
* Performance: Single-query unique shortname resolution via SQL LIKE and in-memory set lookups.
* Performance: Extended exclusions of non-template course artefacts (comments, badges, calendar events, competencies, legacy files).
* Performance: Deterministic cyclic reference collection (gc_collect_cycles()) and context cache reset between work units.
* Performance: Target category capability caching during batch course restorations.
* Performance: Automated background maintenance for stale temporary backup directories (>30 minutes).
* Performance: Module name static caching and query deduplication in resource baseline fingerprinting.
* Benchmark: Dual-pipeline scientific benchmark harness supporting --pipeline=standard|optimized.
